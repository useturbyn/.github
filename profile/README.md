# Turbyn

**Custom code for HubSpot workflows.** Turbyn adds a custom code action to the HubSpot workflows you already have: write JavaScript or Python, use any npm or pip package, test with sample inputs, and publish an immutable build. No Data Hub Professional upgrade required.

- Runs up to 2 hours with up to 8 GiB of memory (plan-dependent)
- Every run isolated in its own sandbox, with a full record of inputs, logs and outputs
- Compatible with existing HubSpot custom code (`exports.main`)
- 60+ ready-to-use recipes: enrichment, routing, validation, ERP sync, PDFs
